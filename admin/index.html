1 · GitHub key (saves your changes)

  1. Open GitHub › New fine-grained token.
  2. Name it portfolio dashboard, set expiry to 1 year.
  3. Repository access: Only select repositories › saarkesh-portfolio.
  4. Permissions › Repository › Contents: Read and write.
  5. Generate, copy it, paste below.

2 · Where to store videos & images

  1. Put upload.php on your CyberPanel site and set UPLOAD_KEY inside it (see SERVER-SETUP.md).
  2. Paste its address and the same key here.
